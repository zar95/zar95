# 🏢 MR Platform — Medical Representative Sales Force Automation

> **Enterprise B2B SaaS platform for pharmaceutical field-force management and sales operations.**

## 📌 Overview

**MR Platform** is a multi-tenant SaaS solution designed for pharmaceutical companies to manage medical representatives, doctors, territories, products, distributors, coverage, and field operations.

The platform uses a **dual-plane architecture** with centralized tenant management and isolated PostgreSQL databases for each pharmaceutical tenant. It is built as an **Nx monorepo** with NestJS backend services and React-based administration portals.

### 🏗️ Architecture

* **Control Plane:** Tenant onboarding, lifecycle management, database provisioning, and platform administration.
* **Data Plane:** One PostgreSQL database per tenant for strict data isolation.
* **Backend:** NestJS, Prisma, PostgreSQL, Redis, JWT authentication.
* **Business Portal:** React-based portal for pharmaceutical company administrators.
* **Owner Portal:** Platform management portal for SaaS administrators.
* **Mobile App:** React Native application for field representatives and sales managers.
